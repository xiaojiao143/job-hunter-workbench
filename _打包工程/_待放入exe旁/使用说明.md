# 求职猎手工作台 · 使用说明

一个装在你自己电脑上的求职管理台。**不联网、不注册、不上传** —— 你的简历、岗位、投递记录全部只存在你自己的电脑上，别人看不到。

---

## 一、怎么装（只有 3 步）

1. 双击 **`求职猎手工作台-安装程序.exe`**
2. 浏览器会弹出一个页面，点大的蓝色按钮「**开始安装**」
3. 装完点「**立即打开工作台**」

装完之后，**桌面上会出现「求职猎手工作台」的图标**，以后直接双击它就行。

> 装到哪：默认装在 `C:\Users\你的用户名\求职猎手工作台`，一般不用改。

**想卸载**：Windows「设置 → 应用 → 找到『求职猎手工作台』→ 卸载」。
⚠️ 卸载会把数据一起删掉，删之前记得先备份（见第五节）。

---

## 二、第一次打开，按顺序做这两件事

### 第 1 步：填模型接口（只做一次）

进左侧「**设置 → ① 大模型接口**」，填三格：

| 填什么 | 填什么内容 |
|---|---|
| Base URL | `https://api.deepseek.com/v1` |
| API Key | 你在服务商那边申请的密钥 |
| 模型名 | `deepseek-chat` |

填完点「**保存配置**」，再点「测试连通」，变绿就通了。

> **不填也能用。** 岗位库、投递看板、面试管理、公司背调、offer 对比都不依赖 AI。
> 只有「AI 解析岗位」「匹配打分」「AI 备面」「自动抓岗位」这几个会灰掉。

### 第 2 步：选一种方式加岗位

**方式一：自动抓（一次捞一批）**

左侧点「**采集岗位**」→ 点「登录检测」→ **会弹出一个 Edge 窗口，用手机扫码登录 BOSS** →
回到工作台填城市和关键词（比如「西安」+「Python」）→ 点开始采集。

> 登录一次之后会记住，以后不用反复扫码。

**方式二：手动粘（最简单，一次一个）**

在招聘网站上把岗位那一段文字选中、复制 → 工作台左侧「**岗位库**」→「**手动导入岗位**」→ 粘贴 → AI 自动拆好字段。

> 拿不准用哪个就先用手动方式。自动抓的价值只是「省掉一个个复制粘贴」。

## 三、各页面干什么

| 页面 | 用途 |
|---|---|
| 岗位库 | 所有岗位的总表，筛选、排序、批量操作 |
| 采集岗位 | 从招聘网站批量抓岗位 |
| 投递看板 | 拖动卡片推进状态：待投 → 已投 → 已读 → 回复 → 面试 → offer |
| 面试管理 | 面试安排、AI 备面、复盘 |
| 待跟进 | 该催的、该复盘的，一次列全 |
| 公司背调 | 投之前先查工商、司法、劳动纠纷 |
| 简历素材库 | 多版本简历；**「上传 PDF / Word」选个文件就自动转成文字**；AI 匹配打分 |
| AI 求职助手 | 按 `Ctrl + K` 随时唤起，问它任何求职问题 |
| 岗位对比 | 多家 offer 并排比 |
| 数据仪表盘 | 投递漏斗、进度总览 |
| 设置 | 模型接口、提示词、主题、备份 |

## 四、⚠️ 自动抓岗位的三个提醒（请认真读）

**1. 有被平台限制的风险。**

自动抓岗位是读招聘网页的数据接口实现的，比手动翻页密集，**可能触发平台风控**（表现可能是临时无法登录）。工具已做限速和冷却，但**不保证不触发**。

**这个风险由你自己承担。** 如果在意，请只用「手动粘贴」的方式加岗位 —— 功能一样完整，只是慢一点。

**2. 采集时别关那个黑窗口，也别关弹出的浏览器。**

关掉黑窗口 = 采集中断。

**3. 采集用你自己的账号登录。**

工具不代填账号密码，也不会替你在招聘网站上发消息、投简历。**投递那一下永远是你自己点的。**

---

## 五、⚠️ 数据安全（一定看完）

**你的数据在哪？** 全在这台电脑的这个浏览器的存储里。不上传、不同步、开发者看不到。

**这意味着三件事：**

1. **固定用一个浏览器打开。** 别一会儿 Chrome 一会儿 Edge —— 数据分开存的，换浏览器等于换了个空工作台。
2. **别用「清理加速」「浏览器清理」类软件。** 它们会顺手把工作台数据一起清掉。
3. **别用无痕模式。**

**怎么备份：** 设置 →「导出全部数据（JSON）」，存一个文件到你硬盘。
**建议每周导一次**，存到网盘或 U 盘。浏览器数据万一出问题，把这个文件导回来就能恢复。

## 六、常见问题

**Q：双击安装程序，什么都没发生 / 浏览器没弹出来？**
A：可能被杀毒软件拦了。先看任务栏有没有一个浏览器窗口。
还是没有的话，右键安装程序 →「属性」→ 底部如果有「解除锁定」勾上它 → 确定，再双击试试。

**Q：提示「Windows 已保护你的电脑」/ SmartScreen 警告？**
A：这是 Windows 对**所有**没花钱买数字签名的软件的统一提示，不代表软件有问题。
点「**更多信息**」→「**仍要运行**」。

**Q：双击桌面图标，弹出黑窗口但浏览器没自动打开？**
A：把黑窗口里「浏览器地址」那一行（形如 `http://127.0.0.1:8738/`）复制，粘到浏览器地址栏回车。

**Q：提示「端口都被占用了」？**
A：说明已经开着一个了。按 `Ctrl+Shift+Esc` 打开任务管理器，找到「求职猎手工作台」结束掉，再重新双击。

**Q：采集那一页点了没反应 / 提示采集器没启动？**
A：说明采集组件没装成功。想自己查原因：进安装目录 → 进「采集组件」文件夹 →
在文件夹空白处按住 `Shift` 右键 →「在此处打开 PowerShell 窗口」→
输入 `.\采集组件.exe where --deep` 回车 → 把输出截图发给提供文件的人。

**Q：简历素材库里怎么把 PDF / Word 简历弄进去？**
A：点「**📄 上传简历文件**」（或空态里的「**📄 上传 PDF / Word**」），选文件就会**自动转成文字**存进来，
不用再自己复制粘贴。支持 `.pdf` / `.docx` / `.txt` / `.md`。
- `.txt` / `.md` 直接读，**不用开着采集器**；
- `.pdf` / `.docx` 由本机采集器代劳 —— 所以要先双击过「启动采集器」；
- **旧版 `.doc` 读不了**：用 Word 打开 →「另存为」→ 选 `.docx` 再传；
- **扫描件 / 图片版 PDF 抽不出文字**（里面是图不是字），需要 OCR。换一份能选中文字的 PDF，或者直接把文字粘进来。

**Q：AI 报错 401 / 402 / 404？**
A：401 = Key 填错了；402 = 账户没钱了，去充值；404 = 地址或模型名不对，检查 Base URL 有没有带 `/v1`。

**Q：能不能在手机上用？**
A：这是电脑版，手机上体验会明显变差，不建议。

**Q：数据会上传吗？**
A：不会。除了你自己填的模型接口（那是你主动填的）会被调用，没有任何数据离开你的电脑。
